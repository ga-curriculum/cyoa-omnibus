## What the heck is this?

The field of data science contains many topics that don't fit our typical 2-hour lesson template. I still want to give you access to this knowledge, so I've allocated time in our calendar for you to watch these lessons pre-recorded. Please watch these lessons at your own pace, making sure to pause/unpause as you see fit. Here is the full list of available CYOA lessons and a description of when/why you might like to watch them:

- [Natural Language Processing with Neural Nets]() (1h2min Recording)
    - How to use deep learning to solve NLP tasks with word embeddings.
    - **Topics Included:** RNNs, NLP, Word Embeddings/Word Vectors, GloVe
- [Additional Topics with CNNs]() (27min + 12min + 19min = 58min Recording Total)
    - Part I: Keras Datasets (ie, reading minibatches from files rather than from RAM)
    - Part II: Data Augmentation
    - Part III: Using Pre-trained Models in Keras
    - **Topics Included:** (I) Keras datasets, generators, (II) Data augmentation, (III) VGG16, convolutional bases, the functional approach to Keras
- [Docker]() (48min Recording)
    - How to use Docker, an extremely popular multi-purpose DevOps tool for automating and containerizing projects.
    - **Topics Included:** Docker, virtualization, Dockerfiles, `tensorflow-gpu`
- [Tensorboard]() (18min Recording)
    - Tensorboard is a model monitoring software that integrates with Tensorflow in the form of a callback. In this lesson, we learn how to create tensorboards to monitor model progress both from a server as well as within a Jupyter notebook.
    - **Topics Included:** Tensorboard, callbacks
